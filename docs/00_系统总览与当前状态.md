## 1. 平台概况

| 项 | 内容 |
|----|------|
| 载体 | 小型双推进器差速 USV |
| 计算 | Jetson NX (ARM64, Tegra)，Ubuntu 20.04 + ROS1 Noetic |
| 定位 | RTK GPS（`/fix`）+ WitMotion IMU（`/imu/data`）+ Livox MID-360 |
| 建图定位 | FAST-LIO LOCALIZATION（`/Odometry`，camera_init 系） |
| 执行 | MCU 串口（`/dev/32port`），PWM 1200~1800，中性 1500 |
| 地面站 | TCP 链路（航点下发 P 帧 / 摇杆 K 帧 / 状态 S 帧） |

## 2. 总体框架（2026-09 当前）

```
┌─ 传感器层 ───────────────────────────────────────────────┐
│ gps_common(/fix)  wit_imu(/imu/data)  livox(/livox/lidar)│
│ FAST-LIO(/Odometry, /prior_map, /cloud_registered_body)  │
└──────────────┬───────────────────────────────────────────┘
               │
┌─ 通信层 ─────┴───────────────────────────────────────────┐
│ tcp(sys_status_node: 地面站↔船)  usart(↔MCU)  logger     │
└──────────────┬───────────────────────────────────────────┘
               │
┌─ 规划/引导层 ─┴──────────────────────────────────────────┐
│ 链A(GPS):  地面站航点 ─→ point_nav_node（角度/速度双PID） │
│ 链B(LiDAR): Hybrid A*/A* ─→ /waypoints_path              │
│             ─→ huamo_node（LOS引导 + 滑模控制 + PWM混合） │
│ [新] rl_local_planner（RL 引导层，Shadow 阶段，未闭环）   │
└──────────────┬───────────────────────────────────────────┘
               │ 都汇入唯一出口
┌─ 控制执行层 ──┴──────────────────────────────────────────┐
│ /auto_thruster_pwm → thruster_manager(模式仲裁+钳位)     │
│   → /controller → usart_node → MCU → 左右推进器          │
└──────────────────────────────────────────────────────────┘
```

要点：
- **`/auto_thruster_pwm` 是唯一执行入口**，thruster_manager 是唯一仲裁者（自主 > 摇杆 > 中性）。
- 实艇主链是 **链A（point_nav）和链B（huamo）**；`follow_controller`/`waypoint_los_pid`/`los_pid_follow` 属于 Gazebo/VRX 仿真链，实艇不跑。
- RL 目标是替换链B 的 LOS 引导段（`guidance.cpp`），底层滑模与 PWM 全部复用——见 05 号文档。

## 3. 坐标系约定（重要）

| 系 | 来源 | 用途 |
|----|------|------|
| `map` | map_server（scans.yaml）/ A* | 全局路径 `/waypoints_path` |
| `camera_init` | FAST-LIO | `/Odometry`、huamo 控制、A* 的 robot_frame |
| GPS ENU | nmeadriver `/vel`、point_nav 角度 | GPS 链专用 |

TF：`map → camera_init` 由 FAST-LIO transform_fusion 提供。
**已知技术债**：huamo 内部有 `+91.5°` 硬编码艏向偏置（雷达安装标定），换雷达/换艇必须重新标定（见 04 号文档 Q5）。

## 4. 当前状态一句话

**原有系统全部可用、未受本轮 RL 改造影响**（改动全部在新增包内，逐项验证见 01 号文档）；RL 处于「Phase 2.5 完成（接口/契约/Shadow 节点已在 NX 实跑验证），Phase 5 huamo 集成未开始」，闭环模式尚未启用，训练在 Windows 训练机进行（见 `rl_local_planner_training/WINDOWS_STEPS.md`）。

## 6. 铁律（所有操作前必读）

1. **同一时间只允许一个 `/auto_thruster_pwm` 发布者**：point_nav、huamo、4 个 adjust_pid 标定节点都发这个话题，同时启动=指令交错=推进器抖动（04 号文档 Q1）。
2. **急停通道**：地面站把 `is_auto_control` 置 false → thruster_manager 立即输出中性 PWM，与上层节点无关、任何时候有效。
3. **RL 永远不直接发 PWM**，训练严禁在艇上运行（NX 只做推理/Shadow）。
4. 出海测试先低速、小范围、开阔水域，LOS 模式随时可回退。

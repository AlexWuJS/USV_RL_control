# 05 · RL 系统说明（rl_local_planner）

> 详细设计见仓库根 `RL_INTERFACE_DESIGN.md`（接口定稿）；
> 训练操作见 `rl_local_planner_training/{README.md, WINDOWS_STEPS.md}`。本文是使用视角的摘要。

---

## 1. RL 在系统中的位置

```
/waypoints_path ──┬─ huamo LOS（现状，保留）──→ /guidance/los_cmd ─┐
                  │                                               ├→ huamo 执行段
                  └─ rl_local_planner_node ──→ /guidance/rl_cmd ──┘  (guidance_mode 选择)
                         │                                                │
                  SAC Actor + Safety Supervisor              speed_huamo / yaw_huamo
                  （不碰 PWM，不碰底层控制器）                 remote_data_deal → /auto_thruster_pwm
```

- RL 只替换 LOS 引导层，输出 `desired_speed + desired_course`（增量式 `Δv_ref/Δcourse_ref` 积分而来）。
- 底层滑模控制、PWM 混合、thruster_manager、急停通道**全部复用现有系统**。
- 急停与 RL 无关：地面站 `is_auto_control=false` → 中性 PWM。
- huamo 未集成前（当前状态），RL 节点只处于 **Shadow** 诊断状态，对航行零影响。

## 2. 环境分工（纪律）

| 环境 | 干什么 | 禁止 |
|------|--------|------|
| 小艇 Jetson NX（本会话） | 接口/契约层、Shadow 节点、Actor 推理（actor.pt）、实艇测试 | **任何训练**（model.learn 等） |
| Windows 训练机 | Gymnasium 环境、SAC 训练、评估 | — |

- 训练/部署**共用唯一契约实现** `rl_common/`：49 维观测（顺序/单位/坐标系/归一化）、动作缩放、安全规则。改动必须两端同步（`sync_rl_common.sh`）并双端跑单测。
- 模型流向单向：训练机 `stageN_actor.pt` → NX `models/actor.pt` → 仅推理。

## 3. Shadow 模式（当前可用）

前提：实艇按现状正常航行（bringup + a_star_demo，huamo LOS 控制）。

```bash
# 无模型（STUB，仅打通数据链）
roslaunch rl_local_planner rl_shadow.launch
# 有模型（训练机拷回的 actor.pt，先 catkin_make --pkg rl_local_planner 生成消息）
roslaunch rl_local_planner rl_shadow.launch model_path:=$(rospack find rl_local_planner)/models/actor.pt
```

节点行为：订阅 `/Odometry` + `/waypoints_path`（TF 转 camera_init）+ `/cloud_registered_body`（36 扇区），构建 49 维观测 → Actor（TorchScript，CPU ~0.02ms）→ 动作积分 → Safety Supervisor → **发布 `/guidance/rl_cmd`（无订阅者，仅记录）**。

输出：
- `/guidance/rl_status`（Float32MultiArray 12 项：u, r, cte, e_heading, d_min, v_ref, course_ref, cmd_speed, cmd_course, supervisor, infer_ms, stub_flag）
- CSV 运行日志（roslaunch 启动时在 `~/rl_logs/`；`python3` 直启在 `/tmp/rl_logs/`）

Shadow 期要验证的事（Phase 5 评审材料）：
1. 观测构建与实艇数据自洽（cte/e_heading 分布合理、无 NaN）
2. `hull_to_sensor_yaw` 标定：用已知方位障碍对比扇区图（默认 0，见 RL_INTERFACE_DESIGN §13.6）
3. ENU→huamo 航向换算实证（LOS 输出 vs RL 坐标系换算差恒 π）
4. tau_u/tau_r 用 shadow 数据回归修正训练动力学

## 4. 闭环模式（Phase 5 之后可用，当前未启用）

前提：huamo_node 完成集成（`guidance_mode` 参数 + 订阅 `/guidance/rl_cmd` + 转发 `/guidance/los_cmd`，约 40 行，设计见 RL_INTERFACE_DESIGN §3）+ shadow 数据评审通过。

```bash
roslaunch rl_local_planner rl_guidance.launch model_path:=.../actor.pt
```

回退三件套：地面站急停（即时）、重启 a_star_demo（回 LOS）、RL 节点崩溃自动回退 LOS（huamo 侧超时判断）。

## 5. 训练机流程摘要

```
1.【Windows】scp 从 NX 拉取 rl_local_planner_training/
2.【Windows】windows_setup.ps1 建环境（自动跑契约单测+冒烟，失败即中止）
3.【Windows】Stage1 无障碍跟踪 → 评估达标 → Stage2 静态障碍 → 评估达标（→ Stage3）
4.【Windows】scp models/stageN_actor.pt 回 NX models/actor.pt
5.【NX】shadow 验证 → Phase 5 集成 → 低速闭环
```
Stage 门槛与常见问题见 `WINDOWS_STEPS.md` §3-§4。

## 6. 关键设计参数速查

| 参数 | 值 | 依据 |
|------|-----|------|
| 观测维度 | 49（4 自身+7 路径+36 扇区+2 上拍动作） | RL_INTERFACE_DESIGN §5 |
| 动作 | [-1,1]² → Δv≤0.1 m/s/步，Δcourse≤0.05 rad/步 | §6 |
| 速度域 | 0.2~2.0 m/s | 实艇 LOS 速度域；滑模无倒车 |
| 安全包络 | 8m 起降速 → 3m 爬行 0.4 → 1.5m 停 | §7 |
| 参考界 | course_ref 偏离路径切线 ≤60° | 防积分漂移 |
| 控制频率 | 10Hz 固定步进（0.1s 节流，与训练 dt 一致；/Odometry 实测 ~100Hz） | §4.3 |
| 动力学 | tau_u=0.79s（huamo.cpp A），tau_r=0.53s（sys_ident Nomoto T） | §9 |
| 训练算法 | SAC（SB3），net [256,256]，γ=0.99 | §9 |

## 2. 水上测试项目（按顺序，每项单独一段录制）

### 项目 1：终点停船验收（LOS，速度闭环 A/B 的 A 趟）

- 上述 launch（`use_pose_speed_diff:=false`）+ 单目标直线 30~40 m；
- **记下终点坐标**（A* 输出或 RViz 读取），项目 3 复用；
- 判据：终点前约 15 m 开始减速 → 停船 → `/auto_thruster_pwm` 回 1500/1500 → 不转圈；
  终端出现 `huamo: 任务结束(到终点/追路停滞)，停车`。

### 项目 2：速度闭环 B 趟（同航线，只切开关）

```bash
# 重启 launch（先 Ctrl+C 旧的），只改一个参数：
roslaunch a_star_planner water_test.launch use_pose_speed_diff:=true
```

- 同一起终点（用项目 1 记下的坐标；`rosrun a_star_planner verify_goal_sequence.py X1 Y1 X2 Y2` 可保证路径完全一致）；
- 与 A 趟背靠背（10 分钟内）；判据：速度波动 ≤±0.1 m/s、PWM 摆率 ≤50/s、CTE 不劣化（数值回岸我出对比表）。

### 项目 3：RL 首航（闭环第一级）

```bash
# 终端 A（控制，切 RL 执行 + 速度闭环开）：
roslaunch a_star_planner water_test.launch \
    guidance_mode:=rl rl_mode:=active use_pose_speed_diff:=true
# 终端 B（RL 切 active，真正下发指令）：
# 先 Ctrl+C 掉 1.4 的 shadow 节点，再：
roslaunch rl_local_planner rl_guidance.launch \
  model_path:=/home/jetson/haique/little-boat-motion-control/message_ws/src/guidance/rl_local_planner/models/stage2_best_actor.pt
```

- 航线：单目标 20~30 m、直线为主、静水无浮标区域、与项目 1/2 同方向更佳；
- **退出机制（按优先级）**：① RL 节点终端 Ctrl+C（rl_cmd 断流 → huamo 0.5 s 自动回 LOS，台架已验证）；
  ② 地面站切手动 `S,0,3,c,@,0,`；③ 实体遥控器（硬件直连最强）；④ 一键清任务：
  `rostopic pub -1 /waypoint_collector/clear std_msgs/Empty` 或
  `rostopic pub -1 /waypoints_path nav_msgs/Path "{}"`；
- 观察点（另一人盯终端）：艇沿路径走、速度被跟踪（实际 vs 期望 ≤±0.15）、无异常振荡、
  `[huamo_exec]` 日志 1 Hz 打印执行链、无看门狗/急停误触发；
- 通过标准：RL 独立完成航线并减速停车、无碰撞、CTE ≤ LOS 的 2 倍、全程无 NaN。

### 项目 4：同航线 LOS 对照跑（RL 的评审参照）

```bash
# RL 节点 Ctrl+C → huamo 自动回 LOS（或直接重启 launch guidance_mode:=los）
roslaunch a_star_planner a_star_demo.launch speed_max:=0.8 guidance_mode:=los use_pose_speed_diff:=true
```

- 与项目 3 **完全相同**的起终点 → 同一条路径 → 同条件对比（CTE/速度/航时）。

### 项目 5：湖心定位专段

- 岸边 → 湖心 → 岸边，匀速直航穿行、湖心**不停留**；
- 手机记"进湖心/出湖心"时刻（与 tee 日志的 fitness 时间线对齐）；
- 产出：湖心 fitness 实际值、漂移速率、回岸能否重锁 → 定 RTK 兜底参数。

### （可选）项目 6：多目标 + abort 回归

- §2.3 流程：2 点 → 4~5 点 → 混一个岸上点看 `ERROR: waypoint N unreachable (abort)` 且艇不动。

## 3. 应急速查

| 场景 | 动作 |
|------|------|
| RL 行为异常 | RL 节点终端 Ctrl+C（自动回 LOS）→ 必要时再切手动/遥控器 |
| 任何紧急情况 | 遥控器直接接管（硬件直连，最强）或 `S,0,3,c,@,0,` |
| 取消任务停车 | `rostopic pub -1 /waypoint_collector/clear std_msgs/Empty` |
| 录制损坏提示 | 当场重录该段；无法重录再打捞：`python3 .../a_star_planner/scripts/bag_scavenger.py 坏包 输出包` |
| RViz 路径残留 | Path 显示项 Buffer Length=1；clear 后无变化检查唯一采集器进程 |

桨在动时**绝不** kill huamo/a_star 进程；停录制只按**一次** Ctrl+C 等提示符。
